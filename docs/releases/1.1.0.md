# ClickControl 1.1.0 — Screen scroll, hold-to-repeat, navigation keys, and UX fixes

Second curated stable release of the Android app, following the generic input and reliability improvements since 1.0.0.

- Add `GenericInput` device control actions (`Single Click`, `Keyboard Input`, `Screen Scroll`) for controlling PDFs, slides, browsers, and other apps alongside Anki and MyWhoosh.
- Add configurable `Screen Scroll` directions (`Up`, `Down`, `Left`, `Right`), step count (`1..20`), area-percentage validation, and swipe dispatch via Android AccessibilityService.
- Add `Page Up`, `Page Down`, `Home`, and `End` portable keyboard keys plus `Repeat while held` for `Single Click` actions.
- Fix `FloatingHudPill` visibility sync on AccessibilityService connect and lifecycle overlay cleanup.
- Fix `MyShiftOverlayCalibrator` boundary clamping, initial portrait pill spacing, and close button placement below the status pill.
- Make `MyWhoosh location` rows fully clickable in Settings and remove duplicate shift test buttons.

The release signing key is preserved (`1.0.0` users can update directly; older debug-signed APKs still require backing up app data and reinstalling before switching to this release key). Signed APK and AAB downloads include verified package metadata and SHA-256 checksums.

Download the APK to install. This release tag publishes the Android artifacts; desktop builds for Ubuntu Linux, macOS, and Windows are published automatically as Desktop Alpha pre-releases from main. Some actions require explicitly enabled Android Accessibility permissions.
